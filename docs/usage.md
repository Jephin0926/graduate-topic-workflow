# 使用指南

## 一、开始前准备

- 一个可进一步拆分的大致研究方向，以及中英文主题词；
- 可用的 LeapSpace；
- 能读取你提供的文件、并结合 OpenAlex 检索的大模型或智能体；
- 通过高校／研究机构图书馆等合法渠道获取重点全文的条件；
- 对培养方案、已有数据、实验与硬件条件、个人目标和选题硬约束的基本判断。

工作台在本地浏览器中运行，不代替上述平台执行检索或写作。

## 二、第一次交互：近年趋势与候选方向

1. 在 **00 个人卡片** 填写研究主题和检索边界。个人条件可在此步填写，但不会进入第一次提示词。
2. 点击“生成 LeapSpace 文献调研提示词”，核对后复制到 LeapSpace。
3. 默认检索 2020 年 1 月 1 日至今，目标是近年趋势与 4—6 个研究方向，不是立即收敛课题。
4. 取回调研报告 PDF 和原始文献元数据 CSV。检查方向定义、检索式、证据与文件是否可读。

## 三、第二次交互：方向文献增补与研究脉络

1. 在 **01 接收调研成果** 上传 PDF 和 CSV，录入 4—6 个方向及一句定义。
2. 选择 OpenAlex key 的使用方式。默认推荐本地环境变量；便捷模式的风险见[隐私说明](privacy.md)。
3. 设置每个方向的精读数量，默认 5 篇、不得少于 5 篇；第二次提示词和 02 的精读槽位会同步使用这一数量。
4. 生成第二次提示词，连同第一次的 PDF 和 CSV 交给所选大模型或智能体。
5. 第二次按方向增补，默认从 2010 年开始；经典文献可突破年份，但须标记。
6. 取回方向研究与精读指南 MD、增补文献 CSV。CSV 应包含第一轮保留文献与第二轮新增文献，每个方向应有设定数量的重点精读文献及选择理由。
7. 抽查 DOI、OpenAlex ID、来源路径和检索失败记录。AI 输出不天然等于真实检索结果。

## 四、获取全文并准备第三次交互

1. 在 **02 文献增补与精读** 上传 MD 和 CSV。
2. 选择 2—4 个优先方向，按 01 设置的数量登记每个方向的重点文献。
3. 通过合法渠道获取全文，逐篇登记“尚未获得”“只有摘要”或“已获得全文”。
4. 只有实际取得并上传 PDF 的文献才标为全文。不要为了追求完整报告而伪造全文状态。
5. 生成第三次提示词，核对其中是否包含你不愿发送的个人条件。
6. 将方向研究 MD、增补 CSV、个人卡片及实际全文交给所选大模型或智能体。

输出规则：

- 无全文：只形成候选框架、待验证清单与精读计划；
- 部分全文：可以形成候选论证，但必须标明证据缺口；
- 重点全文齐备：可以形成完整候选论证初稿，仍需逐项核验。

## 五、保存候选报告并人工复核

1. 将第三次返回的 1—2 份报告上传到 **03 候选选题报告**。
2. 核对题目、科学问题、研究现状、研究内容、可行性、风险和参考文献。
3. 抽查文献事实是否能追溯到元数据或全文位置，确认数据、设备、时间和合规条件。
4. 点击“导出完整档案包”，在“选择导出内容”中按需勾选个人卡片、脱敏进度、三次提示词、各阶段调研成果、精读全文与候选报告，导出带档案清单的 ZIP。所有项目默认全选，也可逐项取消。ZIP 仅用于备份和取回文件，不能直接作为进度导入；单独的 JSON 进度备份仍不含文件本体。
5. 与导师讨论通过、修改或回退方案；最终课题不由工作台或 AI 决定。
