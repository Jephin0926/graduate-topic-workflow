# 隐私与数据边界

## 本地保存不等于绝对安全

工作台没有项目云端后端。进度保存在当前浏览器的 localStorage，上传文件保存在 IndexedDB。清理浏览器数据、更换浏览器或设备，都可能导致本地记录不可用，请及时下载重要文件。

“本地运行”只表示工作台自身不主动把这些数据上传到项目服务器。你把提示词或文件复制、上传给外部 AI 平台后，相应内容会离开本机，并受该平台规则约束。

## 个人卡片

个人卡片包含培养方案、课题组基础、数据与设备、个人目标和选题约束：

- 第一次 LeapSpace 提示词不包含这些内容；
- 第三次候选选题收敛提示词会使用这些内容；
- 发送第三次提示词前，应删除你不愿提供给所选 AI 平台的信息；
- 下载的个人卡片和进度文件应妥善保管，不进入公开仓库。

## OpenAlex key 的两种模式

### 环境变量模式（默认推荐）

工作台不保存 key，第二次提示词要求智能体从本地 `OPENALEX_API_KEY` 环境变量读取。Git Bash 临时配置示例：

```bash
export OPENALEX_API_KEY="你的key"
```

不要把真实 key 写进公开脚本、截图或 GitHub。

### 便捷模式

只有主动选择并勾选风险确认后，工作台才会在当前浏览器保存 key，并写入第二次提示词：

- 浏览器存储不等于加密；
- key 会随提示词发送给所选 AI 服务；
- 导出的进度 JSON 会包含 key；
- 切回环境变量模式会清除工作台中已输入的 key。

公开分享进度、截图或录屏前，必须删除或更换 key。若 key 曾公开暴露，应在服务平台吊销并重置，而不是只删除文件中的文字。

## 论文全文与个人材料

- 只通过有权使用的渠道获取论文全文，不请求或传播未经授权的下载方式。
- 上传全文给 AI 平台前，确认你有权进行该操作，并理解平台的数据处理方式。
- 公开仓库不放论文全文、个人卡片、真实调研附件、校内文件或私人测试数据。
- 演示截图全部使用虚构数据，不能作为真实科研结论的证据。

## 证据边界

AI 生成的文献、引文、趋势和可行性判断必须人工抽查。只有实际提供的全文才能作为“已精读”的依据；摘要和元数据必须明确标注证据范围。最终选题由研究者与导师决定。
